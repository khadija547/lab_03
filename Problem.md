# Problem: Find Even and Odd Numbers
**Algorithm**

1.**Start** the algorithm.   
2.Input a number `n`.    
3.**Compute** the remainder of `n` divided by `2`, i.e., `remainder = n % 2`.  
Check the value of `remainder`:  
- If remainder == 0, go to step 5.
* Else, go to step 6.
**Print** " `n` is Even" and go to step 7.  
**Print** " `n` is Odd" and go to step 7.  
**Stop** the algorithm.  


**Example**     
Input: `n = 7`     
Step 3: `remainder = 7 % 2 = 1`     
Step 4: `remainder != 0`    
Step 6: Print "7 is Odd"    
Step 7: Stop
